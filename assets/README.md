# Brand assets

The app icons are unchanged copies of the super.engineering assets used by
[superdoteng/translations](https://github.com/superdoteng/translations/tree/main/assets).

The files in `badges/` are unchanged [Shields.io](https://shields.io) badges
with [Simple Icons](https://simpleicons.org) glyphs, matching the sponsor badge
used by superdoteng/translations. Discord is a trademark of Discord Inc.; no
endorsement is implied.

The files in `buttons/` are rendered for this repository in GitHub's Primer
button style, with [Primer Octicons](https://github.com/primer/octicons)
(MIT) bug and light bulb icons.

These assets do not grant a license to the proprietary super.engineering app.
