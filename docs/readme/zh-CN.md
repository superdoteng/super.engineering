## 需要提供什么

正在使用智能体？请阅读[智能体指南](../../AGENTS.md)。

[请先搜索已有议题](https://github.com/superdoteng/super.engineering/issues)。如果找到相关报告，请在那里补充有用的信息。

- **错误:** 复现步骤、预期结果以及实际发生的情况。如果可以，请附上“关于 super.engineering”中显示的应用版本以及你的操作系统。
- **功能:** 你要完成的任务、遇到的阻碍以及所需的结果。
- **日志和截图:** 可选。请先检查其中是否有私人信息，或通过邮件发送至 [humans@super.engineering](mailto:humans@super.engineering)。

## 需要帮助？

在 [Discord](https://discord.gg/AJ5BUZSV65) 上提问和分享想法。\
请将安全问题私下报告至 [humans@super.engineering](mailto:humans@super.engineering)。
