[super.engineering](https://super.engineering)은 에이전틱 엔지니어링을 위한 네이티브 워크스페이스입니다. 코딩 에이전트, 터미널, 리뷰를 Rust로 만든 초고속 앱 하나에 모았습니다. 무엇이 고장 났는지, 다음에 무엇이 필요한지 알려 주세요.

## 포함할 내용

에이전트를 사용하시나요? [에이전트 가이드](../../AGENTS.md)를 읽어 주세요.

[먼저 기존 이슈를 검색하세요](https://github.com/superdoteng/super.engineering/issues). 같은 문제의 신고가 있으면 도움이 될 정보를 추가해 주세요.

- **버그:** 재현 단계, 예상한 동작, 실제로 발생한 일. 가능하면 ‘super.engineering에 관하여’에서 앱 버전을 확인하고 운영체제와 함께 적어 주세요.
- **기능:** 하려는 작업, 방해가 되는 점, 필요한 결과.
- **로그와 스크린샷:** 선택 사항입니다. 먼저 비공개 정보가 없는지 확인하거나 [humans@super.engineering](mailto:humans@super.engineering)로 이메일을 보내 주세요.

## 도움이 필요하신가요?

[Discord](https://discord.gg/AJ5BUZSV65)에서 질문하고 아이디어를 나눠 주세요.\
보안 문제는 [humans@super.engineering](mailto:humans@super.engineering)로 비공개로 신고해 주세요.
