<p align="center">super.engineering 的錯誤回報與功能請求。</p>

[super.engineering](https://super.engineering) 是面向代理式工程的原生工作區。它把你的程式設計代理、終端機和程式碼審查整合到一個以 Rust 打造的極速應用程式中。告訴我們哪裡出了問題，以及你接下來需要什麼。

## 需要提供什麼

正在使用代理？請閱讀[代理指南](../../AGENTS.md)。

[請先搜尋現有議題](https://github.com/superdoteng/super.engineering/issues)。如果找到相關回報，請在該處補充有用的資訊。

- **錯誤:** 重現步驟、預期結果及實際發生的情況。如果可以，請附上「關於 super.engineering」中顯示的應用程式版本以及你的作業系統。
- **功能:** 你要完成的工作、遇到的阻礙，以及需要的結果。
- **日誌和螢幕截圖:** 選填。請先檢查是否包含私人資訊，或寄信至 [humans@super.engineering](mailto:humans@super.engineering)。

## 需要協助？

在 [Discord](https://discord.gg/AJ5BUZSV65) 上提問並分享想法。\
請將安全性問題私下回報至 [humans@super.engineering](mailto:humans@super.engineering)。
