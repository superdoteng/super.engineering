<h1 align="center"><span dir="ltr">super.engineering</span></h1>

<p align="center">super.engineering のバグ報告と機能リクエスト。</p>

[super.engineering](https://super.engineering) は、エージェント型エンジニアリングのためのネイティブなワークスペースです。コーディングエージェント、ターミナル、レビューを、Rust 製の超高速なアプリ 1 つにまとめます。不具合や、次に必要な機能をお知らせください。

</p>

## 記載する内容

エージェントを使う場合は、[エージェント向けガイド](../../AGENTS.md)をお読みください。

[まず既存の Issue を検索してください](https://github.com/superdoteng/super.engineering/issues)。同じ問題の報告があれば、役立つ情報をそちらに追加してください。

- **バグ:** 再現手順、期待した動作、実際に起きたこと。可能であれば、「super.engineering について」に表示されるアプリのバージョンと、お使いの OS も記載してください。
- **機能:** やりたいこと、その妨げになっていること、必要な結果。
- **ログとスクリーンショット:** 任意です。先に個人情報が含まれていないか確認するか、[humans@super.engineering](mailto:humans@super.engineering) へメールで送ってください。

## お困りですか？

質問やアイデアは [Discord](https://discord.gg/AJ5BUZSV65) でどうぞ。\
セキュリティの問題は [humans@super.engineering](mailto:humans@super.engineering) へ非公開でご報告ください。
